# المهام 1.5 — Al-Mahamm

تطبيق تسجيل صوتي يدوي لهاتف أندرويد. التسجيل يبدأ فقط عندما تضغط أنت، ويُحفظ داخل التطبيق حتى لو فشل مجلد بطاقة SD.

## تنزيل APK

بعد نجاح البناء، الملف هنا:

https://github.com/uuuuy5283-source/Al-Mahamm/releases/latest

اسم الملف: `Al-Mahamm-1.5.apk`

احذف نسخة 1.4 أولًا ثم ثبّت 1.5. التوقيع مختلف، لذلك التثبيت فوق القديمة يرفضه أندرويد. الحذف يمسح التسجيلات القديمة التي كانت داخل التطبيق.

## ما الذي تغيّر في 1.5

- زر **إيقاف الخلفية** ظاهر في إشعار «المهام» مع زر التسجيل وزر إطفاء الشاشة.
- التسجيل يُحفظ داخل التطبيق أولًا، ثم تُنسخ نسخة إلى المجلد المختار أو إلى `Music/Al-Mahamm` أو `Downloads/Al-Mahamm`.
- فشل المجلد أو منتقي الملفات لم يعد يمسح التسجيل ولا يقفل التطبيق.
- من «تسجيلاتي» يمكن التشغيل، أو المشاركة إلى أي تطبيق، أو حفظ نسخة في مجلد.
- إذا أقفل منتقي ملفات النظام، استخدم المشاركة وتجاوز اختيار المجلد.

## أذونات تحتاجها مرة واحدة

1. الميكروفون.
2. الإشعارات، وإلا لن يظهر زر إيقاف الخلفية في الشريط.
3. استثناء البطارية، ومن شاومي أيضًا التشغيل التلقائي، حتى لا يُقتل التسجيل.
4. إذن الاستخدام اختياري، لتحسين قائمة التطبيقات الحديثة.

أندرويد لا يسمح لتطبيق عادي بإيقاف إجباري صامت لكل التطبيقات. الزر يطلب إنهاء عمليات الخلفية، والإيقاف الإجباري النهائي يبقى من صفحة كل تطبيق.
